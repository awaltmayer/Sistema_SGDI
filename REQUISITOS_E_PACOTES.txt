1. PRÉ-REQUISITOS DE SISTEMA / RUNTIMES
--------------------------------------------------------------------------------
Para executar o projeto localmente na máquina, é necessário ter instalado:

- Node.js: Versão 18.x ou superior (Recomendado: v20 LTS ou v22 LTS)
  Download: https://nodejs.org/
  Verificar no terminal:
    node -v

- Gerenciador de Pacotes: npm (versão 9+ ou 10+) ou pnpm / yarn
  Verificar no terminal:
    npm -v

- Git (opcional, mas recomendado para controle de versão):
  Download: https://git-scm.com/
  Verificar no terminal:
    git --version


2. EXTENSÕES RECOMENDADAS PARA O EDITOR (VS CODE / CURSOR / WINDSURF)
--------------------------------------------------------------------------------

1. Tailwind CSS IntelliSense
   - ID: bradlc.vscode-tailwindcss

3. Prettier - Code formatter

5. TypeScript and JavaScript Language Features
   - (Extensão nativa do VS Code / Cursor)
   - Função: Suporte à tipagem estática e inteligência de código TypeScript 5+.

4. CONFIGURAÇÃO DE VARIÁVEIS DE AMBIENTE (.env)
--------------------------------------------------------------------------------
Para a comunicação com o backend e autenticação, é necessário criar um arquivo
chamado '.env' na raiz do projeto contendo:

VITE_SUPABASE_URL=https://seu-projeto.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sua-chave-anon-ou-publishable-aqui
# (o projeto também aceita VITE_SUPABASE_ANON_KEY como alternativa)

Existe um arquivo modelo pronto na raiz chamado '.env.example'.
Para usá-lo, você pode duplicá-lo e renomeá-lo para '.env'.


5. PASSO A PASSO PARA INICIALIZAÇÃO DO PROJETO
--------------------------------------------------------------------------------
1. Abra o terminal na pasta raiz do projeto (Sistema_SGDI).
2. Instale todas as dependências:
   npm install

3. Crie e preencha o arquivo .env:
   (copie de .env.example)

4. Inicie o servidor de desenvolvimento:
   npm run dev

5. Acesse a aplicação no seu navegador pelo link exibido (normalmente http://localhost:8080 ou http://localhost:5173).

6. Para rodar a suíte de testes:
   npm run test
